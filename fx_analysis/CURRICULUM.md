# FXトレード 勝率80%到達カリキュラム

> 目標: XAUUSD・USDJPYを主軸に、勝率80%・月収600万超えのトレーダーへ

---

## ─── まず現実を把握する ───

### 勝率80%は本当に取れるのか

取れる。ただし条件がある。

バックテスト（2年間 USDJPY 1時間足）の実測値：

| シグナル | 勝率 | 期待値 |
|---|---|---|
| BB単体 | **51.4%** | -3.2p（マイナス） |
| MAトレンド + BB 買い | **66.7%** | +33.3p |
| BB + MACD 買い | **55.6%** | +22.3p |

XAUUSD 日足 5年間：

| シグナル | 勝率 | 期待値 |
|---|---|---|
| RSI 30回復 | **73.9%** | +$273 |
| ダイバージェンス 買い | **67.3%** | +$295 |
| BB -2σ タッチ | **67.6%** | +$257 |

**結論：単体シグナルでは66〜74%が限界。80%は「複数条件の完全一致」時のみ達成できる。**
完全一致の条件を絞る → 出現頻度が下がる → 1週間に1〜3回しか打てない → それでいい。

### 「勝率80%」の正体

```
80%とは = 「A+セットアップだけを打った場合の実測値」

A+セットアップ = 以下がすべて揃った時だけ
 ① 上位足（週足/日足）がトレンド方向を明示している
 ② 主要水平線またはEMAに価格が到達している
 ③ 下位足（1H/15M）で反転シグナルが確認できる
 ④ セッション時間が適切（ロンドン/NY開始1〜2時間）

→ 1つでも欠けたら「エントリーしない」が正解
```

## ─── Phase 0: 思考の土台を固める（1週間）───

### やること

1. **「負けトレードの原因」を1つに絞る練習**
   - 根拠が揃ってないのに入った（= 早すぎ）
   - 根拠が揃ってたのに入らなかった（= 待てなかった）
   - どちらが多いか把握する

2. **「月600万」の道筋を逆算する**

   ```
   月600万 ÷ 20営業日 = 1日30万
   1日30万 ÷ 1トレード（仮） = 30万/トレード

   → まず「1トレードで期待値がプラスになること」から始める
   → 資金が少ない間は % で考える（例: 資金の3%を1トレードで取る）
   → 資金を増やすことより「勝率と再現性」を先に作る
   ```

3. **「自分ルール」の初期ドラフト作成**
   - エントリー条件（最低3つ以上揃ったら入る）
   - エントリーしない条件（決済指標前後 / セッション外 / 根拠1つのみ）

## ─── Phase 1: マーケット構造を読む（4週間）───

### Week 1: トレンドの定義

**学ぶこと**

```
上昇トレンド = 高値切り上げ(HH) + 安値切り上げ(HL) の連続
下降トレンド = 高値切り下がり(LH) + 安値切り下がり(LL) の連続

これが崩れた瞬間 = トレンド転換の可能性
```

**毎日やること（15分）**

1. XAUUSD 日足を開く
2. 直近5本のローソク足でHH/HL/LH/LLをマークする
3. 「今日は上昇トレンドか/下降トレンドか/レンジか」を1行で書く

→ これを21日間続けると「相場の流れを見る目」が完成する

### Week 2: 水平線（主要サポート・レジスタンス）

**引き方の優先順位**

```
① 週足の高値・安値（最重要）
② 日足の高値・安値（重要）
③ きりのいい数字（例: XAUUSD 3000, 3100, 3200）
④ 複数回タッチしたポイント（タッチ回数が多いほど強い）
```

**練習**

- TradingView（無料）でXAUUSD・USDJPYを開く
- 週足/日足で「明らかなレベル」を5本だけ引く（引きすぎない）
- 1週間後、「価格は実際にそこで止まったか」を確認する

### Week 3: マルチタイムフレーム分析（MTF）

**基本の見方（トップダウン分析）**

```
Step 1: 週足・日足で「どちらが強いか（バイアス）」を決める
Step 2: 4H足で「エントリーゾーン（水平線やMA）」を特定する
Step 3: 1H足で「実際のエントリートリガー」を待つ
Step 4: 15M足で「精度の高い入りどころ」を決める
```

**判断フローチャート**

```
日足: 上昇トレンド？ Yes
  ↓
4H足: 押し目（サポートライン or EMAに近い）？ Yes
  ↓
1H足: 反転ローソク足 + MACDゴールデンクロス？ Yes
  ↓
→ A+セットアップ確定 → エントリー検討
```

### Week 4: ローソク足パターンと「だましシグナル」の見分け方

**買いで使えるローソク足（1H足以上で機能）**

| パターン | 形状 | 条件 |
|---|---|---|
| ピンバー | 下ひげが実体の2倍以上 | サポートで出現 |
| 陽線包み足 | 前の陰線を完全に包む陽線 | 下降局面の終盤 |
| モーニングスター | 陰線→小さいローソク→陽線 | 安値圏での出現 |

**だましを見抜く3原則**

```
1. 出来高が少ない時のシグナルは無視（FXはVolume非推奨 → スプレッドで判断）
2. 主要指標発表前後30分はシグナルを無効とする（スパイクで反応するから）
3. トレンドに逆らうシグナルは無視（上昇トレンド中の売りシグナルは信頼しない）
```

## ─── Phase 2: 3つのコアセットアップ（4週間）───

> この3つだけに絞る。他は捨てる。

### Setup 1:「トレンド押し目エントリー」← 最重要・最安定

**条件（全部揃ったらエントリー）**

```
① 日足: 明確な上昇トレンド（SMA20 > SMA50 > SMA200）
② 4H: 価格がSMA20またはBBミッドバンド付近まで押した
③ 1H: MACDゴールデンクロス または RSI 40以下から回復
④ 1H: ピンバーまたは包み足が出現

→ 買いエントリー
→ SL: 直近安値の少し下
→ TP: 直近高値（R:Rが1.5以上であること）
```

**バックテスト根拠（USDJPY 1h 2年）**
- MAトレンド + BB: 勝率66.7%、期待値+33.3pip
- これに「1Hローソク足確認」を加えると推定80%+

**XAUUSDでの特性**
- 金は上昇トレンドが長く続く（2023-2026で$1800→$3300の大相場）
- Setup 1は現状のXAUUSDに特に有効
- SMA50(日足)で止まることが多い → そこが主なエントリーゾーン

### Setup 2:「主要水平線リバウンド」

**条件**

```
① 週足/日足で「明らかな水平線（過去に2回以上機能）」に価格が到達
② 4H: その水平線で反転の兆候（ひげ、陽線転換）
③ 1H: BB -2σ + RSI 30以下から回復 or MACDクロス
④ セッション: ロンドン(15:00-18:00 JST) or NY(21:00-24:00 JST)

→ 水平線で買い（下から触れた場合）or 売り（上から触れた場合）
→ SL: 水平線の反対側（例: サポートで買いなら、SLはサポート-0.5%）
→ TP: 次の主要水平線
```

**バックテスト根拠（XAUUSD日足 5年）**
- RSI 30回復: 勝率73.9%（23回）
- BB -2σ: 勝率67.6%（74回）
- 水平線でこの2つが重なると推定80%+

### Setup 3:「ロンドンブレイクアウト（アジアレンジ抜け）」

**条件**

```
① アジア時間（9:00-15:00 JST）のXAUUSD高値・安値をマーク
② 15:00-17:00 JST（ロンドン開始）に高値or安値をブレイク
③ ブレイクキャンドルが大陽線/大陰線（実体が大きい）
④ ブレイク方向が日足トレンドと一致している

→ ブレイク方向にエントリー
→ SL: アジアレンジの反対端
→ TP: アジアレンジの高さ × 1.5〜2倍
```

**なぜ機能するか**
- ロンドン勢が流動性を取りに来る（アジア時間のストップを狩る）
- 方向が決まると勢いがつく
- USDJPYでは機能しにくい → XAUUSDと EURUSDで使う

**大学生の注意点**: ロンドン開始はJST 15:00〜 → 授業中の場合は価格アラートをセット

## ─── Phase 3: デモトレードで実証（4〜8週間）───

### ルール

```
1. 3つのセットアップのみでエントリー（他は一切打たない）
2. エントリー前に「このセットアップはどれか」を宣言してから入る
3. 毎トレードをjournal_cli.pyに記録する
4. 週1回 analyze コマンドで「どのセグメントが勝率高いか」確認
5. 勝率が70%未満のセットアップは次週から一時停止
```

### KPI（8週間後の目標）

```
総トレード数: 30〜50回
Setup 1 勝率: 75%以上
Setup 2 勝率: 75%以上
Setup 3 勝率: 65%以上
A+セットアップのみ合算: 80%以上

→ 達成できたらライブ口座へ移行
→ 達成できなければ Phase 1-2 の見直し（どこがズレているか特定）
```

### 週次レビュー（毎週日曜 30分）

```bash
python3 journal_cli.py analyze   # 数字で見る

確認すること:
1. 確信度5のトレードの勝率は? （これが80%ないなら根拠の精度が低い）
2. どのシグナルが一番勝率高いか?
3. 負けたトレードの共通点は? （時間帯? セットアップの不完全さ?）
```

## ─── 通貨ペア別 特性メモ ───

### XAUUSD（ゴールド）← メイン

```
特性:
  - 2023年以降 強い上昇トレンド継続中
  - ボラティリティが高い（1日100pip以上も普通）
  - Setup 1（押し目買い）が最も安定して機能
  - 日足RSI 30回復の勝率: 73.9%（5年実績）

注意:
  - 米国CPI・雇用統計・FOMC発表前後は動きが極端
  - アジア時間は比較的静か → ロンドン・NYが本番

活用法:
  → Setup 1: 日足SMA50で押したら1H確認してエントリー
  → Setup 3: 毎朝アジアレンジをマーク → ロンドン開始に備える
```

### USDJPY ← メイン

```
特性:
  - 東京時間（9-15 JST）が最もボリュームあり
  - BOJ政策発表で急変することがある
  - MAトレンド + BB の組み合わせが安定（実績勝率66.7%）

注意:
  - 円高方向へのスパイクが突然来ることがある（介入リスク）
  - 介入は通常 大きな陰線1本で来る → 損切りにひっかかっても仕方ない

活用法:
  → Setup 1: 日足トレンドの方向に4H・1H押し目でエントリー
  → Setup 2: 150円・155円などのキリ番は強いサポート/レジスタンス
```

### EURUSD ← サブ

```
特性:
  - ロンドン時間が最も動く
  - ドルインデックス（DXY）と逆相関
  - トレンドが比較的きれいに出やすい

使い方: Setup 1・2 でUSDJPYと同じアプローチで可
```

### USDZAR ← 特殊

```
特性:
  - スプレッドが広い（コスト高）
  - 新興国通貨なのでボラティリティが高い
  - リスクオフ時に ZAR が売られる（円と逆）

→ 当面はメインに使わない。XAUとUSDJPYで実力をつけてから
```

## ─── チェックリスト ───

### エントリー前（毎回必須）

```
□ 日足のトレンド方向を確認した
□ 現在価格は主要水平線またはEMA付近か
□ 使うセットアップは Setup 1/2/3 のどれか

□ 経済指標発表は30分以内にないか
□ SLの位置を決めた（= 最大損失を許容できる）
□ TP/SLの比率が1:1.5以上（リスクリワード確認）
```

### エントリー後

```
□ journal_cli.py add で記録した
□ 確認したシグナルを全部チェックした
□ 確信度（1〜5）を正直につけた
□ チャートを閉じた（= 見すぎない）
```
