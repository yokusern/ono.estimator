## 0. 神のトレードシステム ─ 全時間足統合エントリー術

> プロが使うマルチタイムフレーム（MTF）分析の完全ガイド。

> **上位足でトレンドを確認 → 中位足でセットアップ → 下位足で精密エントリー**

### MTF（マルチタイムフレーム）の3層構造

```
【第1層: 方向バイアス確定】日足 / 4時間足
  役割: 「今は買い相場か？売り相場か？」を決定する。
  確認事項:
    ✅ SMA20 > SMA50 > SMA200 → 買い方向のみ狙う
    ✅ 価格 > SMA200 → 大局的上昇トレンド
    ✅ RSI 50以上 → 買い方が優勢
    ✅ 日足レベルのサポート/レジスタンスを把握
  絶対ルール: このレイヤーと逆方向のエントリーは禁止。

【第2層: セットアップ確認】1時間足 / 30分足
  役割: 「どのパターンが出ているか？」を判断する。
  確認事項:
    ✅ 上位足方向へのパターン発生（モーニングスター、ダブルボトム等）
    ✅ インジケーターの同調（MACD GC、RSI 30回復、Stoch GC）
    ✅ 重要な価格レベル（水平線、BB端、Fib）付近での発生
    ✅ ロンドン/NY時間内（東京時間はパス）
  このレイヤーでセットアップが確認されたらエントリー準備。

【第3層: 精密エントリー】15分足 / 5分足
  役割: 「いつ、どこでポジションを持つか」を決定する。
  確認事項:
    ✅ インサイドバーの上方ブレイク
    ✅ ハンマー/ピンバーの出現（反転の最終確認）
    ✅ MACD ヒストグラムのゼロライン超え
    ✅ 損切りラインの明確化（直近安値の下）
  ここでエントリーすることでSL（損切り幅）を最小化できる。
```

### 実践例：XAUUSD 上昇トレンドでの買いエントリー

```
STEP 1 【日足確認】
  → SMA20 > 50 > 200 ✅ / RSI 55 ✅ / 価格が日足サポート付近 ✅
  → バイアス: 買い方向のみ狙う

STEP 2 【4h足確認】
  → 4h足でモーニングスターが出現 ✅
  → RSIが30から回復 ✅ / MACDヒストグラムがプラス転換 ✅
  → セットアップ確認 → エントリー準備

STEP 3 【15分足でエントリー】
  → 15mでハンマー出現 ✅ + インサイドバー上抜け ✅
  → 損切り: 15mハンマーの下ひげ先端の下
  → 利確1: 4hの直近高値 / 利確2: 日足の次のレジスタンス
  → ロット: 損切り幅から逆算（口座の1〜2%リスク）
```

```

  → 5mで値動きが収束（インサイドバー）したら、
     高値ブレイクの確定足でエントリー
  → メリット: SL幅が極めて小さい

方法②: ハンマー/ピンバー確認
  → サポートレベルで5mハンマーが出たら次の足でエントリー
  → メリット: 反転の最終確認ができる

方法③: MAクロス（EMA5 × EMA20）
  → 5mで短期EMAが長期EMAを上抜けた瞬間エントリー
  → メリット: シンプルで判断が速い
  → 注意: 必ず上位足トレンドと同方向のみ

共通ルール:
  - 1分足は使わない（ノイズが多すぎる）
  - 東京時間の5m/15mシグナルは無視
  - SLは必ず設定（5mでも例外なし）
```

## 1. 時間足別 最強シグナル一覧

> 同じシグナルでも時間足によって信頼性が大きく変わる。あなたのトレードスタイルに合った足を選ぶ。

### 5分足（5m）
**スタイル**: 超短期エントリー専用。スキャルピング。
**メモ**: ⚠️ 単独使用禁止。必ず1h/4hのセットアップ確認後に使う。ノイズが多い。
**この足での最強パターン**: インサイドバー上抜け / ハンマー（サポート付近） / EMA5×EMA20クロス

### 15分足（15m）
**スタイル**: エントリー精密化。4h/1hのセットアップを下位足で確認。
**メモ**: ✅ 短期エントリーの推奨足。5mよりノイズが少なく、信頼性バランスが良い。
**この足での最強パターン**: インサイドバー上抜け / ブルフラッグ上抜け / ハンマー + ピンバー

### 30分足（30m）
**スタイル**: 1hと15mのブリッジ。1h確認 → 30m精密化 → エントリー。
**メモ**: ✅ 使いやすい。勝率の安定性と出現頻度のバランスが良い。
**この足での最強パターン**: モーニングスター / ダブルボトム（小） / MACD GC

### 1h足（1時間）
**スタイル**: デイトレード。1日数回のエントリーチャンスがある。
**メモ**: ✅ 標準足。4hでセットアップ → 1hでエントリーの組み合わせが最強。
**この足での最強パターン**: モーニングスター / 強い陽線 / ダイバージェンス 買い / MACD GC / ブル・ピンバー

### 4h足（4時間）
**スタイル**: スイングトレード。1週間で数回のエントリー。大学生に最適。
**メモ**: ✅ 最推奨。授業中でもアラートで管理でき、エントリー頻度も適切。
**この足での最強パターン**: ダブルボトム + ダイバージェンス / RSI 70割れ + 強い陰線 / モーニングスター + RSI / BB -2σ + ピンバー

### 日足（1d）
**スタイル**: ポジショントレード。数週間〜数ヶ月保有。
**メモ**: ✅ 最も信頼性が高い。RSI 30回復が日足では勝率73.9%（PF 6.13）
**この足での最強パターン**: RSI 30回復 / モーニングスター + 下方ダマシ / BB -2σ + ピンバー / ダイバージェンス + ダブルボトム

## 2. ローソク足パターン辞典

> 形を認識したら根拠（WHY）を確認 → 条件が揃っているか → 確率を参照 → エントリー判断。

### 📊 モーニングスター
**形状の定義**: 陰線（大）→ 小さい実体/ドージ → 陽線（大）の3本セット

**価格アクションの意味（買い方・売り方の攻防）**

1本目の大陰線: 売り方が完全に主導権を持ち、価格を大きく押し下げた。
2本目の小さい実体（ドージ）: 売り方の勢いが落ち、買い方が抵抗し始めた「均衡点」。
この瞬間に機関投資家が静かに買いポジションを積んでいることが多い。
3本目の大陽線: 買い方が主導権を奪い返し、2本目の高値を大きく上抜けた。
売り方の損切りを巻き込みながら急騰するため、勢いが出やすい。

**ダウ理論との関係**

下降トレンド = 「高値切り下がり + 安値切り下がり」の連続。
モーニングスターの3本目陽線が直前の「戻り高値（ローカルトップ）」を更新すると、
初めて「高値切り上がり」が成立 → ダウ理論的トレンド転換の第一段階。
その後、前回安値を割らずに新高値を更新 → 転換完全確定。

**最重要ポイント**
「価格が安値に達したのに売り方はそれ以上売れなかった」という事実がパターンに刻まれている。
これが機関投資家の「買い意欲」を間接的に示す。

**最も有効な時間足**: 4h > 1d > 1h（時間足が高いほどノイズが少なく信頼性が増す）
**避けるべき状況**: レンジ相場中央で出現 / トレンドなし環境 / 東京時間
**理想的な条件（最高確率）**: 日足の下降トレンド末期 + 週足サポートライン + RSI 30〜40

### 📊 ハンマー
**形状の定義**: 小さな実体（上部）+ 実体の2倍以上の下ひげ + 上ひげなし or 小

**価格アクションの意味**

そのローソク足の時間帯内で、いったん売り方が大きく価格を押し下げた（下ひげの長さ）。
しかし終値は大きく戻り、実体の位置が上部に来た。
これは「売り圧力を買い方が完全に吸収した」ことの証拠。

**下ひげが長いほど意味が強い理由**

下ひげ = 「その価格では売れなかった（買い需要があった）」エリア。
長い下ひげ = 大量の買い需要（＝機関投資家の指値買い）がその価格帯に存在することを示唆。
重要なサポートライン（過去の高安値、BBバンド下端）でのハンマー = 機関の買いゾーン確認。

**ダウ理論との関係**

ハンマーが出現した安値が「前回安値より高い位置」にある場合 →「安値切り上がり」。
その後高値を更新すれば「高値切り上がり」も確認 → 上昇トレンド転換確定。
ハンマー単体ではなく、次の足の終値がハンマーの実体を上回ることで確認する（確定1本待ち）。

**注意**

確定1本待ちが鉄則。次の足が陰線なら無効（ダマシ）。

**最も有効な時間足**: 1h > 4h（スキャルピングから短期スイングに有効）
**避けるべき状況**: 下降トレンド中の戻り（レジスタンス付近） / 出来高が少ない時間帯
**理想的な条件（最高確率）**: サポートライン + BBバンド-2σ付近 + RSI 30以下

### 📊 陽線包み足
**形状の定義**: 前の陰線の始値・終値を完全に包む大きな陽線

**価格アクションの意味**

前の足: 売り方が主導権（陰線）。
今の足: 買い方が前の足の動き全体を「上書き」する大陽線。
これは単なる反発ではなく「支配権の交代」を示す。

**なぜ1本足より2本足が信頼できるのか**

1本の陰線後の反発 = ランダムかもしれない。
しかし陰線全体を包む陽線 = 買い方が強い意志を持って大量に買ったことを示す。
特に高出来高（FXではスプレッド縮小や急激な動き）を伴う包み足は機関介入の証拠。

**ダウ理論との関係**

包み足が出現した地点が「安値切り上がり」になっていると、ダウ理論の転換条件を満たす。
下降トレンド末期 → 包み足（=高値切り上がり候補） → その後安値を守る → 転換確定。

**ポイント**

大きな包み足ほど信頼性が高い（実体が大きい = より多くの参加者が転換に賭けた）。

**最も有効な時間足**: 4h > 1h

### 📊 ダブルボトム
**形状の定義**: ほぼ同じ価格帯で2回安値をつけてから上昇するW字パターン

**価格アクションの意味と形成メカニズム**

1回目の安値: 売り方が積極的に売り込んだ結果の安値。しかしここで買い方が反発させた。

**ダウ理論との関係**

最も教科書的なダウ理論転換パターン。

### 📊 ダイバージェンス

**価格アクションの意味（最も高度なシグナル）**

「価格は下がっているが、下げる力（モメンタム）が弱まっている」ことを示す。

RSI = 14本の平均上昇幅 ÷ 平均下落幅 × 100。

しかしRSIが前回より高い → 前回ほど「強く売られていない」= 売り方の勢いが落ちた。

### 📊 上昇三角形ブレイク
**形状の定義**: 水平な上値抵抗線 + 切り上がる下値支持線（上方ブレイク）

**なぜ上昇三角形は買いシグナルなのか**

水平な上値抵抗: 「その価格では売り方が必ず出てくる」水準。一定の売り圧力がある。
切り上がる下値支持: 押しが入るたびにより高い水準で止まる = 買い方が積極的に買っている。

つまり「売り方は同じ水準でずっと売っているが、買い方は段々と高い水準で買い始めた」。
時間が経つほど買い方が有利になり、最終的に売り方の売り圧力を消化してブレイク。

**ダウ理論との関係**

三角形内の安値が切り上がり続けることで「安値切り上がり」を連続して形成。
水平抵抗線のブレイク = 「高値切り上がり」の確定 = 上昇トレンド開始確認。

**ブレイクの「本物」と「ダマシ」の見分け方**

本物のブレイク: 強い陽線・大きいバーでのブレイク / ロンドン・NY時間 / RSIが50以上
ダマシのブレイク: 小さい陽線でブレイク / 東京時間 / 直後にバンドの下に戻る

**エントリー方法**

①ブレイク足の確定でエントリー（勢いに乗る）
②ブレイク後のプルバック（三角形上端への戻り）でエントリー（リスク小）
損切り: 三角形内に価格が戻ったら即撤退
利確: 三角形の高さ分を上方向に投影した価格

**避けるべき状況**: 三角形が小さすぎる（10本以下） / 収束が不明確

### 📊 ヘッドアンドショルダー
**形状の定義**: 左肩 → 頭（最高値）→ 右肩（左肩に近い高さ）→ ネックライン割れ

**3つのピークが示す「買い方の敗北プロセス」**

左肩: 最初の買い攻勢で新高値。しかしその後押し戻された。
頭: 買い方の二度目の試み。左肩を上回る新高値を記録したが、ここでも押し戻された。
→「最高値を更新したのに、もっと上がらなかった」= 高値圏での買い需要の限界。
右肩: 三度目の試み。しかし今度は頭の高値を超えられなかった（高値切り下がり！）。
ネックライン割れ: 買い方が完全に撤退し、売り方が主導権を握った確定瞬間。

**ダウ理論との完全一致**

ダウ理論的転換条件: 「高値切り下がり + 安値切り下がり」。
H&Sでは:
- 頭 → 右肩で「高値切り下がり」が確定
- ネックライン割れで「安値切り下がり」が確定
→ 2条件同時成立 = 下降トレンド開始の最も教科書的なシグナル。

**エントリーと利確の計算**

エントリー: ネックラインを明確に割り込んだ確定足
損切り: 右肩の高値の上
利確: 頭からネックラインまでの高さ分をネックラインから下方向に投影

**よくある失敗**

ネックライン割れ直後ではなく「プルバック（ネックラインへの戻り試し）」を待つと安全。
多くの場合、割れた後に一度ネックラインまで戻してから下落が加速する。

## 3. インジケーター辞典

> 各指標が「何を測っているのか」を理解することで、ダマシを見抜く力が身につく。

### 📈 ボリンジャーバンド
**計算式**: `移動平均線（中心線）± 標準偏差 × 2`

**何を測っているか**

ボリンジャーバンドは「統計的に見て価格がどれだけ中心から外れているか」を可視化する。
価格が±2σの範囲に収まる確率は統計理論上95.4%。
つまり-2σに触れることは「統計的に見て過剰に売られた（上位2.3%の安値）」を意味する。

**なぜ単体では機能しにくいのか**

統計は「正規分布」を仮定するが、相場価格は正規分布しない。
特に強いトレンドでは「バンドウォーク」が発生し、価格が長時間バンド沿いを動く。
XAUUSDの上昇トレンド中: +2σタッチが「売り」ではなく「上昇の加速」を示すことがある。

**最も効果的な使い方（データ実証済み）**

【レンジ相場】バンド収縮後の拡張: バンド幅が縮小した後の拡大（スクイーズ）はブレイクアウトの予兆。
【トレンド相場】中心線をサポート/レジスタンスとして使う: 上昇トレンド中は中心線（SMA20）で押し目買い。
【最強】MAトレンド + BB-2σ: 上昇トレンド中にBB-2σまで押した時の買い → USDJPY 1h 66.7%。

**時間足別の信頼性**

1h: ノイズが多い / 4h: バランスが良い / 1d: 最も信頼性高い
→ 日足BBの-2σは「年に数回の絶好の買い場」として機能する。

**時間足別信頼性ランク**: 1d ＞ 4h ＞ 1h
**最も効果的なペア**: USDJPY（トレンドが明確で機能しやすい）
**やってはいけない使い方**: ❌ XAUUSDでのBB+2σ逆張り売り（EV -$81、機能しない）

### 📈 MACD
**計算式**: `12EMA - 26EMA = MACDライン / 9期間EMA(MACD) = シグナルライン`

**何を測っているか**

MACDは「短期トレンド（12本）と長期トレンド（26本）の乖離」を測る。
MACDがプラス = 短期トレンドが長期より上 = 「足元の勢いが強い」状態。
ゴールデンクロス = 足元の勢いが長期平均を上抜けた瞬間 = モメンタム転換。

**ゴールデンクロスの意味（ダウ理論的解釈）**

GC直後は「短期的な上昇の始まり」を示す。
ダウ理論では「トレンドは明確な反証まで継続」とされるが、
MACDのGCは「売りトレンドが買いトレンドに切り替わった証拠（モメンタムの転換）」として機能。

**ヒストグラムの使い方**

ヒストグラム（MACDとシグナルの差）が縮小 → 勢いが落ちている（逆転の予兆）
ヒストグラムがプラスに転換 → 上昇モメンタム開始のサイン
→ GCを待たずに「ヒストグラムの底打ち」でエントリーするとより早い。

**時間足別の特性**

短時間足（15m, 1h）: GC後の勢いが続かないことが多い（ノイズ多）。
4h: バランス良好。
1d: 日足GCは数週間〜数ヶ月の上昇トレンド開始を示すことが多い。

**最強組み合わせ**

MACD GC + RSI 30〜50（買われすぎでない）: 信頼性向上。
MACD + モーニングスター: XAUUSD 1h 74.1%（27回）。

**時間足別信頼性ランク**: 4h ＞ 1d ＞ 1h
**最も効果的なペア**: USDJPY / EURUSD（トレンドが比較的きれいに出る）
**やってはいけない使い方**: ❌ レンジ相場でのMACDシグナル（ダマシが頻発）

### 📈 RSI（相対力指数）
**計算式**: `14本の平均上昇幅 ÷ (平均上昇幅 + 平均下落幅) × 100`

**何を測っているか**

RSIは「14本間の上昇力と下落力の比率」。
RSI 30以下: 「この14本間は下落一辺倒だった（売り方が優勢すぎた）」= 売り方が疲弊した可能性。
RSI 70以上: 「この14本間は上昇一辺倒だった（買い方が優勢すぎた）」= 買い方が疲弊した可能性。

**なぜ「回復」がシグナルになるのか**

RSI 30割れではなく「RSIが30を上回った瞬間（30回復）」がシグナル。
これは「売り方の圧力が頂点を過ぎ、買い方が巻き返し始めた」ことの確認。
30を超えた時点でエントリー = 底から少し遅れるが確認後の安全なエントリー。

**ダイバージェンスとの組み合わせが最強**

価格: 前回安値より低い新安値
RSI: 前回より高い（売り方の勢いが弱い）
→「価格は下がったが売り方の体力は落ちている」= 反転間近の強いシグナル。

**時間足別の特性**

1h以下: 30/70の到達が頻繁すぎてシグナルが多すぎる。
4h: バランス良好。回帰性（一方向に振れすぎた後は戻りやすい）が機能しやすい。
1d: XAUUSD日足RSI30回復: 勝率73.9%（PF 6.13！）= 最高の信頼性。

**実データ最強シグナル**

XAUUSD 日足 RSI 30回復: 勝率73.9% / 平均益 $+442 / 平均損 $-204 / PF 6.13
→ 日足でRSIが30以下から回復したら絶好の買い場。過去23回中17回勝利。

**時間足別信頼性ランク**: 1d ＞ 4h ＞ 1h
**最も効果的なペア**: XAUUSD（日足RSI 30回復が圧倒的）
**やってはいけない使い方**: ❌ 強いトレンド中のRSI 70で売り（トレンド継続で損失が膨らむ）

### 📈 ストキャスティクス
**計算式**: `（終値 - 14本の最安値）÷（14本の最高値 - 最安値）× 100 = %K / 3日移動平均 = %D`

**何を測っているか**

ストキャスは「直近14本の値幅の中で、現在の終値がどの位置にあるか」を測る。
%K = 80以上: 14本の高値圏にいる（買われすぎの可能性）
%K = 20以下: 14本の安値圏にいる（売られすぎの可能性）

**RSIとの違い**

RSI = 上昇力 vs 下落力（勢いの比較）
Stoch = 現在値の位置（レンジ内のどこにいるか）
→ レンジ相場ではStochが有効、トレンド相場ではRSIが有効。

**GCシグナル（ゴールデンクロス）の意味**

%Kが%Dを下から上抜け = 足元の値動き（%K）が平均（%D）を上回った = 上昇モメンタム開始。
20以下（売られすぎ圏）でのGC = 「底値圏から上昇へ転換」の確認。

**時間足別の特性**

スキャルピング（5m, 15m）: レンジ環境なら有効。
1h: バランス良好。RSIと組み合わせると信頼性向上。
4h以上: ゆっくりすぎてエントリーが遅れやすい。

**最強組み合わせ**

Stoch GC + モーニングスター: XAUUSD 1h 75.0%（$+331）
Stoch GC + RSI 30回復: XAUUSD 1h 67.2%（$+145）

**時間足別信頼性ランク**: 1h ＞ 4h（レンジでは最強だがトレンドでは機能落ちる）
**最も効果的なペア**: EURUSD / USDJPY（レンジが出やすいペア）
**やってはいけない使い方**: ❌ 強いトレンド相場（上昇中にずっと「買われすぎ」を示し続ける）

### 📈 移動平均線（SMA/EMA）
**計算式**: `SMA: N本の終値の単純平均 / EMA: 指数加重移動平均（直近重視）`

**トレンドの「骨格」を示す**

移動平均線は過去N本の平均価格 = 「平均的なホルダーのコスト」。
価格 > SMA200: 「200本前から持っている投資家が全員含み益」= 上昇トレンドの強い確認。
価格 < SMA200: 「長期保有者が含み損」= 下降トレンドの確認。

**SMAの並び（パーフェクトオーダー）**

買いのパーフェクトオーダー: 価格 > SMA20 > SMA50 > SMA200
→ 短・中・長期のすべてのトレンドが一致している強い上昇相場。
このような環境での押し目買いが最も安全。

**ゴールデンクロス / デッドクロスの意味（ダウ理論）**

GC（短期MAが長期MAを上抜け）= 「短期的な方向性が長期的な方向性を上回った」= トレンド転換。
ダウ理論的には「高値切り上がりの確認」に相当することが多い。

**時間足と期間の使い分け**

スキャルピング（1m-15m）: SMA20, 50
デイトレード（1h）: SMA20, 50, 200
スイング（4h, 1d）: SMA20, 50, 200 + 週足のMA

**最重要**: SMAは単独では弱い。「SMAをフィルターとして使い、エントリーはローソク足シグナルで」が原則。
USDJPY 1h「MAトレンド + BB買い」: 勝率66.7%（24回）→ MA×BBの組み合わせで威力倍増。

**時間足別信頼性ランク**: 1d ＞ 4h（トレンド把握）/ 1h（エントリーフィルター）
**最も効果的なペア**: 全ペアで有効（最も普遍的なツール）
**やってはいけない使い方**: ❌ レンジ相場での単独シグナル（GC/DCのダマシが頻発）
