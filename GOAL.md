# Project Goal (Koshi): ONO Estimator Ultra

This document outlines the ultimate vision for the ONO Estimator Ultra platform. All future development should align with these core objectives.

## 1. Autonomous Monitoring & Intelligent Notification
- **24/7 Operation**: The system runs continuously on a server, monitoring global markets.
- **Milestone Analysis**: Gemini AI triggers deep analysis whenever key technical milestones (support/resistance, crossovers, pattern completions) are reached.
- **Mobile Integration**: Sends real-time "Reason-backed Notifications" to mobile devices, ensuring the user is informed of critical opportunities without active monitoring.

## 2. Visualization of Time-Series Predictions
- **Predictive Charting**: Beyond historical data, the chart must visualize future scenarios.
- **Price & Time Targets**: Draw clear prediction lines indicating "which price" will be reached by "what time."
- **Scenario Probability**: Every prediction must be accompanied by a "Probability Percentage (%)" calculated via AI/Statistical models.

## 3. Immediate Strategy Verbalization
- **Strategic Context**: Upon opening the dashboard, the system immediately presents a summarized "Strategic Rationale" based on recent market movements.
- **Recommended Actions**: Clear, actionable advice (e.g., "Wait for pullback," "Enter at X," "Hedge current position") is displayed prominently to guide decision-making.
